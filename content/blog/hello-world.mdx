## Why Build a Personal Website?

In 2026, having a personal website is still one of the best ways to showcase yourself. Compared to social media, a personal website gives us 100% control — from design to content, from tech stack to deployment method.

## Tech Stack

This website is built with:

- **Next.js 15**: React full-stack framework, supporting SSG/SSR with built-in image optimization
- **Tailwind CSS 4**: Atomic CSS framework for extremely fast development
- **MDX**: Embed React components in Markdown — writing blog posts like writing code
- **Lucide Icons**: Lightweight icon library, tree-shakeable

## Design Philosophy

I aimed for **simplicity, speed, and maintainability**:

1. **No database**: All content is static files — version control and deployment are trivial
2. **Responsive-first**: Consistent great experience from mobile to desktop
3. **Dark mode**: Respecting the user's visual preference
4. **SEO-friendly**: Every page has its own meta tags
