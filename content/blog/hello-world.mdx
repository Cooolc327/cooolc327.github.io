## 为什么搭建个人网站？

在 2026 年，拥有一个个人网站仍然是展示自己最好的方式之一。与社交媒体相比，个人网站给予了我们 100% 的控制权——从设计到内容，从技术栈到部署方式。

## 技术选型

这个网站使用了以下技术栈：

- **Next.js 15**：React 全栈框架，支持 SSG/SSR，内置图片优化
- **Tailwind CSS 4**：原子化 CSS 框架，开发效率极高
- **MDX**：在 Markdown 中嵌入 React 组件，写博客就像写代码
- **Lucide Icons**：轻量级图标库，tree-shakeable

## 设计理念

我追求的是 **简洁、快速、可维护**：

1. **无数据库**：所有内容都是静态文件，版本控制和部署极其简单
2. **响应式优先**：从手机到桌面，一致的良好体验
3. **深色模式**：尊重用户的视觉偏好
4. **SEO 友好**：每个页面都有独立的 meta 标签
