## Background

At the 2026 CEEES Deep Learning Week Hackathon, my team and I developed **HaLoop** — a safe, human-governed AI coding assistant. The core philosophy was: **AI can assist with coding, but critical decisions must remain under human control**.

## Problem Statement

AI coding assistants (like GitHub Copilot, Cursor, etc.) can dramatically increase development speed, but they also introduce safety risks:

- Directly modifying sensitive paths (auth modules, database migrations, dependency files)
- Generating code that may contain security vulnerabilities
- Lack of accountability — who approved the AI's changes?

Our solution was to insert a **governance layer** between the AI and the codebase.

## Technical Architecture

We designed a three-layer architecture:

1. **IDE Layer**: VS Code extension, integrated into the developer's daily workflow
2. **Governance Layer**: Next.js dashboard for approvals, policy, and audit
3. **Persistence Layer**: SQLite (Demo) / PostgreSQL (Production)

### Key Design Decisions

**Dual Risk Evaluation**: We perform risk evaluations on both the backend (during AI plan generation) and the frontend (after plan returns), taking the maximum score as the final risk level. This prevents single-point misclassification.

**SSE + Polling Dual Channel**: Approval decisions are delivered via both Server-Sent Events and HTTP polling, ensuring timely decision delivery even under unstable network conditions.

**Dead Man's Switch**: All AI-modified files are recorded in a Session Manifest, enabling one-click rollback when things go wrong.

## Lessons Learned

1. **Design the contract before implementation**: API contracts (request/response formats) should be established first — they guide parallel frontend and backend development
2. **Demo mode is critical**: Judges needed to run the project without full infrastructure. The SQLite + JSON demo mode made the project work out of the box
3. **Product thinking**: Technical excellence is just the foundation — helping judges quickly understand your value proposition is equally important

## Closing Thoughts

A hackathon is not just a competition — it's an opportunity to rapidly learn and validate ideas. If you have an idea, go build it!
